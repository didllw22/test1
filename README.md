# Premium Checklist Web App

This workspace contains a React + Vite frontend and a separate Express backend stub.

## Frontend

Location: `frontend`

- React + Vite
- Tailwind CSS
- lucide-react icons
- Glassmorphism / premium SaaS UI

Run:

```bash
cd frontend
npm install
npm run dev
```

## Backend

Location: `backend`

- Express API stub
- CORS enabled

Run:

```bash
cd backend
npm install
node server.js
```
